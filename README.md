# DBA361 - Macy's Pizza Database System

## Project Overview

This project was developed as part of the DBA361 Database Development module at Belgium Campus.

The project involves designing and implementing a relational database for a pizza restaurant using SQL. It demonstrates database design, normalization, and the creation of relationships between tables.
The database manages customer information, menu items, orders, employees, and payments using a relational database design.
